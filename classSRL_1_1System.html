SRL::System Class Referencefinal

Detailed Description

System-level hardware control and BIOS services.

Provides a modern C++ interface to the Sega Saturn BIOS service routines. Each method maps to a function pointer stored in the system work area (0x6000000-0x6000FFF).

Warning
SCU interrupt-related operations and clock changes must only be performed from the master SH2. Using them from the slave SH2 is undefined.
Basic Usage:
// Set up interrupt mask allowing only V-Blank
System::SetInterruptMask(~static_cast<uint32_t>(Interrupt::Mask::VBlankIn));
// Read current clock mode
auto clock = System::GetClockMode();
