Fxp SRL::Math::Types::Vector2D::Dot ( const Vector2D & vec) const
inlineconstexprinherited

Calculate the dot product of this vector with another vector.

Parameters
vecThe other vector.
Returns
The dot product as an Fxp value.

Computes the dot product using the formula: X*vec.X + Y*vec.Y. The dot product represents the cosine of the angle between two vectors multiplied by their lengths.

Example usage:

Vector2D v1(1, 0); // Unit vector along X
Vector2D v2(0, 1); // Unit vector along Y
Fxp dotProduct = v1.Dot(v2); // Returns 0 (perpendicular vectors)
Vector2D v3(1, 1);
Vector2D v4(2, 3);
Fxp dotProduct2 = v3.Dot(v4); // Returns 5 (1*2 + 1*3)
